Round Timer

One timer for the whole room. Everyone who opens the same link sees the same clock, whether they’re in the classroom or on a video call.

TipHow this timer stays in sync

Pressing Start now puts the start time in the page link. Anyone who opens that link (via the QR code, a video-call chat, or Canvas) sees the same phase and countdown, because the timer runs off each device’s clock instead of a shared screen. Every pod rotates together without anyone calling time.

  • Pods of mixed sizes? Set the pod size to the largest pod. Smaller pods finish early and go on to the Discussion.
  • Sound: each device has to turn on the chime once, because browsers block sound until you click something.
